### 🧭 [Detour](https://github.com/B9R9/discover)
*A mobile exploration app where the map stays hidden under fog until you go and discover places.*
 
- You spot a place by its bird's-eye direction, walk there and photograph it in the app
- GPS checks at capture time (50 m radius, accuracy limits, mock locations refused) unlock the map around it
- **Local-first**: positions, paths and photos stay on the device (SQLite, MapLibre)
- Expo / React Native app, Node.js API on PostgreSQL + PostGIS (Supabase), npm-workspaces monorepo with shared types
**Status:** in development
